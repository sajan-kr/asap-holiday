# ASAP Holidays - Travel Website

A modern, attractive travel website built with React and Vite, featuring a complete redesign of the ASAP Holidays travel booking platform.

## Features

- **Responsive Design**: Fully responsive layout that works on all devices
- **Modern UI**: Clean, attractive design with smooth animations and transitions
- **Travel Packages**: Showcase of trending travel packages with pricing
- **Destinations**: Beautiful destination cards for various travel locations
- **Why Choose Us**: Feature highlights explaining the benefits
- **Testimonials**: Customer reviews and ratings
- **Contact Information**: Complete footer with contact details and newsletter signup

## Tech Stack

- **React 19**: Latest React with modern hooks and features
- **Vite**: Fast build tool and development server
- **CSS**: Modern CSS with custom properties and responsive design
- **ESLint**: Code linting for quality assurance

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:5173](http://localhost:5173) in your browser

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
